# Bunker Calculator — деплой без покупки хостинга

Это один-единственный HTML-файл (никакого React, никакой сборки, никакого
ИИ-API) — поэтому деплой даже проще, чем у Laytime Calculator.

Единственная правка относительно версии, которая работала внутри Claude:
`window.storage` заменён на localStorage браузера прямо внутри `index.html`
(см. первый `<script>` блок) — по тем же причинам, что и в Laytime
Calculator: этот API существует только внутри Claude. Сохранённые профиль
судна и маршруты — локальные для конкретного браузера/устройства.

## Как задеплоить (тот же принцип, что и раньше)

1. Создайте новый репозиторий на GitHub (отдельный от Laytime Calculator —
   это отдельное приложение) и загрузите туда `index.html` через
   "Add file → Upload files" → Commit.
2. Зайдите на vercel.com → Add New → Project → выберите этот репозиторий →
   Import.
3. Никаких переменных окружения тут не нужно — просто нажмите Deploy.
   Framework Preset может остаться "Other" — для простого статического
   HTML это нормально, Vercel и так отдаст файл как есть, без сборки.
4. Через минуту получите постоянную ссылку вида
   `https://bunker-calculator-yourname.vercel.app`.

Всё остальное (GitHub-аккаунт, Vercel-аккаунт) уже создано на прошлых
шагах — здесь просто ещё один, отдельный проект поверх них.
